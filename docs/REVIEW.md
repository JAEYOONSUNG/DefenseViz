Independent input, analysis and renderer reviewers cross-checked each other's work. Actual Claude Opus critique reviewed the implementation and rendered PNGs; the review was read-only and did not execute tests. Root independently executed the regression and installation checks. The final Claude closeout found no unresolved High findings or blockers; its readiness verdict was conditional on the final tests, installation and native-folder runs, which passed locally.

- Reviews can no longer masquerade as native retained decisions, native systems, run identities or member retention. Per-sample native-artifact and current protein hashes are required.
- Missing ledgers, malformed outputs, stale inputs and implementation changes abort publication before the final output directory is created. Empty tables retain headers and explicit endpoint availability.
- Native IDs and schema variants, legacy workbook dimensions, contradictory duplicate context, IIG/Type-IV taxonomy and exact CasFinder namespaces are handled explicitly. Original memberships and producer metadata are preserved.
- Typed totals exclude non-RM sentinels and partition over displayed types. Conflicting saved/reviewed assignments fail; unrelated decisions cannot turn a row's unknown state into zero.
- DNMB retention, typed pool, atlas Pool/Shared and context/orphan counts carry assessment states. No common complete source scope produces an NA overlap panel. Original source counts never receive DNMB additions.
- Complete native cores require exact known provider/run/system identities and compatible replicons. Review contexts bind current proteins and explicit integrated members; they cannot trigger automatic native-core rules. Complete-core membership and individual catalytic annotation remain separate.
- Import warnings reach inspection, CLI results and receipts. Exact executed commands deliberately retain machine-specific paths for execution provenance; relative input references are not a promise to scrub all upstream metadata.
- Small-cohort headings, category order, type-number alignment, independent Total/Effector count columns, dual mechanism bands and missing-data displays are tested using native-format examples, not only hand-built plotting fixtures.

Raw motif flags, domains, orthology and inter-tool agreement are not automatically treated as nuclease function or activity. Remaining evidence limitations are documented in [the saved-output guide](suite.md). See [executed validation](VALIDATION.md) for the current test scope.

# Historical independent critique and resolution log

The analysis, IO and rendering components were implemented with separate ownership and then cross-reviewed by developers who did not write the reviewed components. Root reruns the integrated tests and verifies real stored data independently.

## Scientific and data-contract findings resolved

- Missing caller output could be mistaken for zero selected calls: final-member coverage now explicit; HMM/reference records do not imply final output completeness.
- Reference-only providers could appear as native callers: auxiliary evidence providers are separate, without name-based exceptions.
- Native genes without system IDs could yield false zero system counts: unknown counts are null and explicitly scoped.
- Control C/Aux roles could enter R/M/S scoring: preserved in the R-M pool but outside score scope.
- Known gene/evidence sequence hashes could conflict: incompatible bindings now fail; incomplete evidence remains unassessed.
- Empty or unmatched extensions could bypass registry/rule validation: all configured contracts and source bindings are checked before filtering candidates.
- Reference FASTA raw input hashes were omitted: recorded and stability-checked alongside normalized sequence identities.
- Repeated anchor enrichment could duplicate profiles: exact source-bound reapplication is idempotent.
- Native feature sequence hashes did not reach admission: existing hashes are lifted through explicit adapters, with disagreement rejected.
- Modified policy parameters retained preset labeling: custom overrides now carry parameter differences and distinct status.
- Default display categories could overwrite explicit input classification: explicit input/user-map precedence is enforced.

## Engineering and figure findings resolved

- Staging absolute paths broke relocation equivalence: generated provenance uses config-relative presentation pointers, with actual file hashes retained in receipts.
- Excel extra documentation differed from packaging: standardized on `.[excel]`.
- Caller headers, long titles and rotated family labels could overlap: measured wrapping and dynamic layout bounds replace fixed assumptions.
- Dollar signs could activate math parsing in identifiers: text is literal, including malformed math-like strings.

- Windows cross-drive source paths raised relative-path errors: explicit absolute provenance fallback now preserves those sources.
- Windows legacy locale broke Unicode fixture/layout writes: all affected paths use explicit UTF-8, tested without changing global locale settings.

## Operational scope

Use a fresh output target for each run. Do not let unrelated programs concurrently write the same destination directory; such external writers are outside the output transaction contract. Clean installation tests use a new virtual environment and a built wheel. No source detector, structure prediction or recognition-specificity code is run by this package. Saved structural/context facts remain upstream inputs; their raw computation is not reconstructed from a bare caller table.
