# Reviewed benchmark figures

The README shows the reviewed 52-genome Geobacillus benchmark generated by the DNMBsuite project workflow. These exports include saved numerical evidence, study-specific context review and sample annotations. The B. coagulans DSM 1 case table is analyzed as a separate project and does not contribute to the 52-genome totals.

| Endpoint | CDSs |
|---|---:|
| Integrated annotations | 2,929 |
| Assigned R–M, types I–III | 342 |
| Assigned type IV | 151 |
| Assigned R–M, including type IV | 493 |
| Effector annotations | 497 |
| Prioritized annotations | 500 |

These sets overlap and should not be added together. In the figures, **assigned** means a CDS-level annotation; orphan components and incomplete contexts remain identified. It does not imply a complete or experimentally active system. Historical decision fields and the `retained_RM_annotations.tsv` filename retain their existing names for compatibility.

In the type tables, DF, PAD and DP count CDSs in the R–M type pool that each tool called in any defense family. They show CDS inclusion, not agreement on the R–M type; PADLOC PDC-S or DMS_other calls, for example, are counted. R(n) and M/S(n) give incomplete R contexts and included orphans; (—) marks a positive count whose context or orphan status was not assessed.

The priority panel counts DNMB-selected or reviewed R subunits and nuclease effector annotations; these assignments do not establish enzyme activity. The `retained_RM_annotations.tsv` export contains policy-selected CDSs, while reviewed additions remain in the integrated annotation list.

Four methylase CDSs are reassigned to BREX (two), DISARM (one) and Hma (one) by the family-scope rules. The three rules use source-bound DNMB curation and complete PADLOC system context, and they were written to formalize these four reviewed corrections from this benchmark. Their agreement with the reviewed result is therefore by construction, not independent validation. The rules contain no sample- or locus-specific branches, but other methylase-containing systems (for example BREX types I, II, V and VI, or DISARM type I) are not covered, and no reassignment is made when the native export lacks DNMB curation columns. Original scores and methylase evidence remain in the audit outputs.

The regenerated analysis matches the archived reviewed result across 56,353 CDS membership, role, source-overlap and count comparisons, which include the four reassignments above. A separate check covers 21,736 rendered values and geometry assertions. This verifies reproduction of the reviewed annotation dataset, not experimental activity or independent biological accuracy. The 52-genome run evaluates saved evidence; it does not rerun search engines. The synthetic demo is a separate dataset.
