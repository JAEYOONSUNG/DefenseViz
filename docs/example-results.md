# Reviewed benchmark figures

The README shows the reviewed 52-genome Geobacillus benchmark generated by the DNMBsuite project workflow. These exports include saved numerical evidence, study-specific context review and sample annotations. The B. coagulans DSM 1 case table is analyzed as a separate project and does not contribute to the 52-genome totals.

| Endpoint | CDSs |
|---|---:|
| Integrated annotations | 2,929 |
| Assigned R–M, types I–III | 342 |
| Assigned type IV | 151 |
| Assigned R–M, including type IV | 493 |
| Effector annotations | 497 |
| Prioritized annotations | 500 |

These sets overlap and should not be added together. In the figures, **assigned** means a CDS-level annotation; orphan components and incomplete contexts remain identified. It does not imply a complete or experimentally active system. Historical decision fields and the `retained_RM_annotations.tsv` filename retain their existing names for compatibility.

In the priority panel, “Active R” denotes DNMB-selected or reviewed restriction-role annotations; it is not a measurement of enzyme activity. The `retained_RM_annotations.tsv` export contains policy-selected CDSs, while reviewed additions remain in the integrated annotation list.

Four methylase CDSs are reassigned to BREX, DISARM and Hma by the current family-scope review. The rules use source-bound DNMB curation and complete native component context; the four target identities are not configured as exceptions. Original scores and methylase evidence remain in the audit outputs.

The regenerated analysis matches the archived reviewed result across 56,353 CDS membership, role, source-overlap and count comparisons. A separate check covers 21,726 rendered values and geometry assertions. This verifies reproduction of the reviewed annotation dataset, not experimental activity or independent biological accuracy. The 52-genome run evaluates saved evidence; it does not rerun search engines. The synthetic demo is a separate dataset.
